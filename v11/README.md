# 全球气候观测 V11

V11 以 V10 为基础，保留气候、人口及独立中国进出口航运地图，新增同页双站完整报告。

## 使用

点击地图站点进入报告，选择“站点对比 · 选择其他站点”，按城市、站点代码或国家搜索并选择。电脑宽屏左右显示当前站点及对比站点的两份完整报告；窄屏和手机上下排列，可使用顶部“查看当前站点报告”“查看对比站点报告”跳转。可更换或取消对比站点，不会重新加载当前站点。

两份报告各自保留 V10 的温度、湿度、闷热、干湿热分级、月度、每日、小时曲线、气候总结、太阳辐照和紫外总量分析，以及阈值设置、重试、CSV/长图导出和打印。只展示原报告，不生成差值或合并对比图表。

年份仍为2025，各站点按自己的 IANA 当地时区（含夏令时）分析。缺测不填零；太阳及 UVA＋UVB 紫外数据为 NASA POWER 格网估计，累计单位 MJ/㎡，紫外只显示每月和全年。气象与辐照在线加载，任一站点失败独立显示原因及重试，不改用其他站点或本地逐小时数据。

报告右侧保留固定返回 V11 主页按钮。V10 历史版本完整保留。其他数据来源、风险分类、航路估算和许可见 [V10说明](../v10/README.md)。
