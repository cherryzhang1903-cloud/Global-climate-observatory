[打开 V4 网站](https://cherryzhang1903-cloud.github.io/Global-climate-observatory/v4/index.html) · [吐鲁番 V4 报告示例](https://cherryzhang1903-cloud.github.io/Global-climate-observatory/report/index.html?station=51573&scheme=4)

- 全年累计辐照量、完整日平均辐照量、最大小时平均辐照度。
- 月累计图、全年每日曲线、可选择当地日期的逐小时曲线，以及月度完整度明细。
- 累计辐照量和所有辐照量图表使用 **MJ/㎡**；日平均值为 MJ/㎡/日。辐照度是功率，另以 W/㎡ 表示。
- 导出全年逐小时 CSV，保留 UTC、当地时间、辐照量与小时平均辐照度。
- NASA 独立加载，失败可单独重试，不阻塞温湿度报告；缺失不补零。

数据按站点经纬度读取 NASA POWER 的 `ALLSKY_SFC_SW_DWN`（全天空地表水平短波辐照）。这是网格估计值，不是气象站辐射仪实测，也不是紫外线辐射。请求明确使用 UTC，并补取前后跨年边界日，再按站点 IANA 当地时区汇总；不使用 NASA 默认当地太阳时冒充行政当地时间。

小时接口返回 Wh/m² 时，乘以 0.0036 转为 MJ/㎡。一小时辐照量除以 0.0036，得到该小时平均辐照度 W/㎡。完整日包括该当地日期实际应有的全部小时（夏令时可能为 23 或 25 小时）。不完整日/月的累计值留空；全年不完整时不显示完整全年总量，另列“有效小时累计”并报告有效小时数。极夜的有效零值保留为零。

太阳辐照按需下载当前站点，不批量抓取全部站点。V3 Excel 仍是原评分快照，**不包含 V4 新下载的逐小时辐照曲线，也不会自动重算首页评分**。在线 NASA 数据更新后可能与原工作簿辐照量存在差异。

核验示例：吐鲁番（51573）、2025 年、Asia/Shanghai，当次 NASA 响应含 8,760 个有效小时、365 个完整日，累计约 6,058.2 MJ/㎡（数据源 SYN1DEG；后续上游修订可能改变结果）。

来源与时间口径：[NASA POWER 小时 API 官方说明](https://power.larc.nasa.gov/docs/services/api/temporal/hourly/)。V3 入口继续保留；下文风险分与分类规则同样适用于 V4。

## 1. 先区分三种不同概念

|概念|表达什么|显示位置|
|---|---|---|
|气候类型|低热暴露、干热主导、湿热主导、干湿混合|首页点位形状、筛选与报告站点信息|
|综合风险等级|综合风险分对应的 1—5 级|首页点位颜色；极寒地区优先显示蓝色|
|AH / HH 小时分级|某一个小时的温度与露点组合|详细报告中的干湿热分级与小时统计|

因此，“HH2 小时较多”与“首页为湿热主导型”不是同一个判定。V3 首页气候类型直接根据干热风险分与湿热风险分判断。

## 2. V3 四类气候类型的判定

令 **D = 干热风险分，W = 湿热风险分**，范围均为 0—100。分类使用原始数值，不先四舍五入。这里的 30、60 是风险分阈值，不是温度、相对湿度或发生概率。

按以下顺序判定：

|顺序|条件|类型|符号|
|---|---|---|---|
|1|D ≤ 30 且 W ≤ 30|低热暴露型|圆点|
|2|D = 60 且 W = 60|干湿混合型|菱形|
|3|D ≥ 60 且 W ≤ 60|干热主导型|叉号|
|4|W ≥ 60 且 D ≤ 60|湿热主导型|方块|
|5|其余所有组合|干湿混合型|菱形|

混合型包括两项均大于 60、两项同时大于 30 且小于 50，以及没有落入其他条件的剩余区间。**混合型不要求两个分数接近，也不表示干湿热小时各占一半。** 低热暴露型也不代表全年没有高温小时。

```python
def climate_type(dry, wet):
    # 输入必须是有效的 0—100 数值；缺失值不能补为 0。
    if dry <= 30 and wet <= 30:
        return "低热暴露型"
    if dry == 60 and wet == 60:
        return "干湿混合型"
    if dry >= 60 and wet <= 60:
        return "干热主导型"
    if wet >= 60 and dry <= 60:
        return "湿热主导型"
    return "干湿混合型"
```

## 3. 干热与湿热风险分如何计算

首页沿用 2025 年风险评分工作簿中的风险分。V3 的分类调整不会改变这些风险分。

### 3.1 小时暴露比例

令 Nt 为温度与露点同时有效的小时数：

```text
基础干热暴露 = (AH1 + AH2) / Nt
极端干热暴露 = (AH3 + AH4) / Nt
基础湿热暴露 = (HH1 + HH2) / Nt
极端湿热暴露 = (HH3 + HH4) / Nt
```

AH / HH 的逐小时判定见第 5 节。分母使用联合有效小时，不把缺失记录计为无热暴露。

### 3.2 标准化

各指标以整个 12,967 站点评分样本的第 5、第 95 百分位数进行截尾归一化：

```text
N(x) = clip((x − P5) / (P95 − P5), 0, 1)
```

clip 表示将结果限制在 0—1。P5、P95 来自完整评分样本，网页筛选国家或地区时不会重新计算。风险分是相对于这组站点的比较值；更换样本或年份后应重新校准，不能直接混用不同批次的分数。

### 3.3 加权公式

```text
D = 100 × [0.35 × N(极端干热暴露)
         + 0.25 × N(基础干热暴露)
         + 0.15 × N(年平均温度)
         + 0.15 × N(全年辐照)
         + 0.10 × N(100 − 年均相对湿度)]

W = 100 × [0.30 × N(极端湿热暴露)
         + 0.25 × N(基础湿热暴露)
         + 0.15 × N(年平均温度)
         + 0.15 × N(年均相对湿度)
         + 0.10 × N(全年辐照)
         + 0.05 × N(ln(1 + 年降水量))]
```

年平均温度单位为 ℃，相对湿度为 %，年降水量为 mm；全年辐照使用原评分工作簿中的 NASA POWER 年度辐照数据。在线 Meteostat 小时下载不提供这一整套风险评分输入。权重是本项目的环境风险评价设置，分数不能解释为老化概率或使用寿命。

## 4. 综合风险等级、颜色与极寒标记

```text
综合风险分 S = 0.5 × D + 0.5 × W
极端风险分 S_peak = max(D, W)
```

“极端风险分”与“AH3/4、HH3/4 极端小时”是不同概念。

|综合风险分 S|等级|默认颜色|
|---|---:|---|
|0 ≤ S < 20|1|深绿色|
|20 ≤ S < 40|2|浅绿色|
|40 ≤ S < 60|3|黄色|
|60 ≤ S < 80|4|橙色|
|80 ≤ S ≤ 100|5|红色|

**年平均温度 ≤ −20 ℃** 的站点，Excel 的“极寒地区”列标为“是”，网页优先用**蓝色**显示，保留原气候类型符号。极寒标记不改变 D、W、综合风险分或四类气候类型，依据的是原工作簿年度均温，而不是某一天最低温。

## 5. 详细报告中的 AH / HH 逐小时分级

T 表示小时气温，Td 表示小时露点温度，单位均为 ℃。每个有效小时最多归入下表一个等级；未满足条件的小时不归入 AH / HH。

### 湿热 HH

|等级|条件|
|---|---|
|HH1|26 ≤ T < 30，且 20 ≤ Td < 24|
|HH2|26 ≤ T < 30 且 Td ≥ 24；或 30 ≤ T < 35 且 20 ≤ Td < 24|
|HH3|30 ≤ T < 35 且 Td ≥ 24；或 T ≥ 35 且 20 ≤ Td < 24|
|HH4|T ≥ 35，且 Td ≥ 24|

### 干热 AH

|等级|条件|
|---|---|
|AH1|35 ≤ T < 40，且 10 < Td ≤ 15|
|AH2|35 ≤ T < 40 且 Td ≤ 10；或 T ≥ 40 且 10 < Td ≤ 15|
|AH3|T ≥ 40，且 5 < Td ≤ 10|
|AH4|T ≥ 40，且 Td ≤ 5|

干热强调较高气温与较低露点；湿热强调气温与较高露点共同出现。露点衡量空气水汽状况，不能直接用相对湿度数值替换上述 Td 阈值。

当露点缺失而气温与相对湿度有效、相对湿度 RH > 0 时，报告可用 Magnus 近似推算露点：

```text
γ = ln(RH / 100) + 17.62 × T / (243.12 + T)
Td = 243.12 × γ / (17.62 − γ)
```

无法取得有效温度或露点的记录不补零。报告内可调的高温、湿度等分析阈值只影响对应分析项目，不会自动修改这里的固定 AH / HH 分级或首页风险分与气候类型。

### 与旧版 AH2 / HH2 标签的区别

旧版首先根据 AH / HH 总暴露小时比例判定是否低热暴露（小于 5%），再用各等级 1、2、3、4 的小时加权结果比较干湿热贡献；单一方向占比达到 70% 时判为主导，否则为混合，再按平均等级形成 AH2、HH2 等标签。

V2 与 V3 已改为第 2 节的风险分 30 / 60 规则。旧标签在 Excel 的“原气候类型”列保留作追溯，不能拿它覆盖“V3气候类型”。报告中仍可统计 HH2 小时，这并不冲突。

## 6. V3 在线气象数据与当地时间

首页站点目录、风险分、四类类型及极寒标记来自已发布的 2025 年评分快照。点击站点进入报告后，按需在线读取 Meteostat 年度小时文件：

```text
https://data.meteostat.net/hourly/{year}/{station}.csv.gz
```

无需用户提供 API 密钥，也不依赖本机预先保存的全年小时文件。请求失败或数据缺失时显示相应状态，不用其他站点冒充当前站点。上游数据可能修订或包含模型补充，报告会展示有效记录数；在线结果可能与原工作簿的年度统计有差异。

**在线读取不会自动重算首页风险分、四类类型或极寒标记。** 如需更新评分年度，必须重新获取完整评分输入并执行统一评分与发布流程。

原始小时数据按 UTC 解释，按站点对应的 **IANA 当地时区**转换后，再做日、月、年统计。跨年边界需要时读取相邻年度文件；夏令时日期可能有 23 或 25 个小时，重复的当地小时仍以不同 UTC 时刻保留。导出数据保留当地时间与 UTC 以便检查。最高温时刻由真实数据决定，不人为移动到下午。

原始评分集从 13,000 个温度完整度大于 95% 的站点出发，剔除 31 个降水缺失站点及另 2 个联合覆盖率不足 95% 的站点，形成当前 12,967 站点集。缺失值不补零。

## 8. 使用方法与数据来源

1. 打开 V3 首页，通过国家、风险等级、气候类型等条件筛选。
2. 查看散点图与地图：形状表示气候类型，颜色表示综合风险或极寒标记。
3. 悬停查看站点名称和分数，点击进入该站点全年分析报告。
4. 报告按需加载在线数据，并以站点当地时间进行温度、湿度、干湿热、月度、每日与小时分析。
5. 用 Excel 对照站点、分数、分类与时区；跨版本比较时先检查评分样本和统计口径。
