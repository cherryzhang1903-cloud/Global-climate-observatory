# 全球气候观测 V10

V10基于V9.1，增加独立的“中国进出口航运”地图模式。切换到该模式时隐藏气候点位和人口栅格，港口与航路可单独调整透明度；0%时同时关闭其点击命中，切回原模式保留气候与人口设置。

港口目录使用官方NGA World Port Index快照，共3,807条记录；地图只显示目录中的中国港口及相关海外港口。航线展示限定为中国港口与海外港口之间的参考联通航线，不展示完整全球海路网或纯海外港口间航线。中国港口识别包含来源字段中的China、Hong Kong、Taiwan、Macau/Macao；原始港口属性仍保留来源记录。

可点击港口查看名称、位置、规模及已提供设施，点击中国进出口参考航线查看对应港口、距离和估算时间。自定义查询要求起终点一端为中国港口，另一端为海外港口，支持双向查询。航道以Eurostat/Marnet海路网计算，时间明确为估算，不是实际贸易统计、船公司班期或运输时效承诺。

保留12,967站2025气候风险、30°经纬网、站点固定经纬度、WorldPop2026人口模型栅格、各层透明度、右侧固定返回按钮，以及当地时间Meteostat和NASA POWER太阳/紫外UVA＋UVB报告（MJ/㎡）。
