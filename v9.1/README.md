# 全球气候观测 V9.1

地图增加30°主要经纬网：经线每30°一条，纬线为赤道、南北纬30°和60°。经纬线由MapLibre原生图层绘制，度数标签随缩放、拖动及旋转同步定位；赤道和本初子午线加深显示。站点提示保留站点的固定经纬度。地图不再显示鼠标位置的经纬度。

站点全年气候报告右侧固定“返回主页”按钮。桌面在右侧居中，手机在右下角，滚动到报告中部或底部均可返回V9.1主页。打印时隐藏。

保留V9的12,967站2025年气候风险、30/60分类、极寒蓝色、国家名称提示、三种图层模式与独立透明度，以及气象数据概览的全年太阳/紫外UVA＋UVB辐照量（MJ/㎡）。气象和辐照按站点当地时间汇总，缺失不补零。

人口数据：WorldPop / University of Southampton，Global2 R2025A v1，2026年模型估计（含外推），原生30角秒、赤道附近约1km，CC BY4.0。人口格网与2025年气候站点属于不同年份；放大不增加数据原始精度。数据与制图口径见[V9数据说明](../v9/README.md)。
