# 全球气候观测 V11.1

以 V11 为基础，保留完整双站报告、气候与人口地图、中国进出口航运，以及 Meteostat 官方数据中转。

- 搜索使用预建文本索引，最多显示20个结果，精确站点代码优先；输入不重复扫描排序整个完整目录。使用精简目录，保留当前报告实例和设置。
- 图表滚动到相应章节附近时才生成；页面保留全年原始数据，未按采样删减气象记录。导出和打印前补齐全部章节。
- 报告标题与站点对比按钮同排；删除顶部返回风险分布与主题按钮，保留右侧固定返回主页。
- 在线数据、当地时区、模型来源及许可说明放到每份报告最后。
- 删除湿热HH1–HH4及干热AH1–AH4明细表，保留等级统计、图表、风险分类规则。

年份仍为2025；各站点按各自IANA时区（含夏令时）分析，缺测不补零。太阳和UVA＋UVB紫外累计单位MJ/㎡；紫外仅每月及全年。气象优先使用新版官方年度数据，官方历史归档回退会明确标注，不改读本地逐小时文件或其他站点。

### 2026-11-01 连续下拉优化

温湿度散点改用Canvas保留全部有效小时点、月份颜色、阈值线和悬停读数，不再为每条记录生成SVG节点；日期标签按已转换的当地时间字符串生成，避免每小时反复建立国际化格式器。报告高度更新按帧合并；保留首次进入章节时生成图表，取消iframe内会造成空白/高度跳变的content-visibility缓存。

本机双站连续下拉测试，最长单次滚动约4.25秒降到0.32秒，最大连续主线程任务约1.87秒降到0.14秒；完整报告每站约2.2万个元素降到约4千个。网络和电脑性能仍影响实际响应。全年记录、统计和导出不删减。
